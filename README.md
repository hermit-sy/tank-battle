# 钢铁风暴 · 坦克大战 (Steel Storm)

一个纯 HTML5 Canvas 实现的经典坦克大战游戏，无需任何依赖，双击即可游玩。

## 玩法

- 控制你的坦克，摧毁每一波来袭的敌军坦克
- **保护基地**（底部中央的旗帜）——基地被摧毁即游戏失败
- 击毁敌军坦克可获得分数，随机掉落强化道具

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `W A S D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| 按钮 🔊 | 静音 |

## 地形与道具

| 元素 | 说明 |
| ---- | ---- |
| 🧱 砖墙 | 可被子弹摧毁 |
| 🛡 钢墙 | 无法摧毁，可当掩体 |
| 🌊 水域 | 坦克无法通过，子弹可穿过 |
| 🌲 树林 | 坦克可穿过并隐蔽，子弹可穿过 |
| ⛳ 基地 | 必须保护的旗帜 |

| 道具 | 效果 |
| ---- | ---- |
| ❤ | 增加一条生命 |
| ★ | 提升火力等级 |
| 🛡 | 获得护盾 |
| ⚡ | 提升移动速度 |

## 运行

直接用浏览器打开 `index.html` 即可。也可以部署到 GitHub Pages：

1. 进入仓库 **Settings → Pages**
2. Source 选择 `Deploy from a branch`
3. 选择 `main` 分支、`/ (root)` 目录，保存

## 技术栈

- 原生 JavaScript + Canvas 2D
- Web Audio API 音效
- 单文件，无外部依赖
